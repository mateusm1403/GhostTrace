# GhostTrace
Plataforma local de Deception Technology em Python para geração de HoneyTokens, monitoramento de acessos suspeitos e análise comportamental (threat scoring). Desenvolvida com FastAPI e HTMX, funciona de forma plug-and-play e offline para simular e detectar scans, brute force e recon. Ideal para laboratórios de Blue Team e estudos.
